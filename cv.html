22. Deploy works in staging, fails in prod

Question EN
Answer EN
Question VI
Answer VI

Tell me about a time deploy worked in one environment but failed in another.

This showed up a lot with multi-env CI/CD. Staging looked fine, prod failed after release. I compared recent commits, env config, secrets, and service versions first. Usually it was a missing env var, different web-server config, or a dependency only present in one environment. I fixed the config, redeployed, and updated the checklist so the same gap wouldn’t repeat.

Kể về lần deploy chạy ở một môi trường nhưng fail ở môi trường khác.

Hay gặp với CI/CD nhiều môi trường. Staging ổn, prod fail sau release. Tôi so commit gần đây, config env, secret và version service trước. Thường là thiếu env var, cấu hình web server khác, hoặc dependency chỉ có ở một bên. Tôi sửa config, deploy lại, và cập nhật checklist để không lặp.

S: Multi-env web/mobile pipelines at Akktis.

T: Find why prod failed while staging passed.

A: Diff env/config/secrets/versions; fix gap; verify; document checklist.

R: Prod recovered; fewer repeat env-drift surprises.

Say this: When staging ≠ prod, I diff environments before rewriting code.

Describe a cloud connectivity issue you had to fix.

A common Cloud Run pain is the app deploys, but database calls fail. I check logs first, then connection string, network path, and service account permissions. Often it’s wrong DB host/socket setup or the runtime identity missing access. I fix the connection config and permissions, redeploy, and confirm with a health check query.

Cloud Run hay gặp: deploy được nhưng gọi database fail. Tôi xem log trước, rồi connection string, đường mạng, và quyền service account. Thường sai host/socket DB hoặc identity thiếu quyền. Tôi sửa config kết nối và permission, deploy lại, rồi confirm bằng health check query.

S: GCP backends on Cloud Run + Cloud SQL.
